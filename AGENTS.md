# Public contribution instructions

Read `PRIVACY.md` before preparing any public commit or PR. Keep private authoring outside this repository. Run the staged and outgoing-commit privacy checks before Git or API uploads, and preserve intentionally public upstream examples and engineering evidence.

This repository renders the GitHub profile README, not an application. Edit
profile claims and project links in README.md; keep contribution rules here and
upload checks in PRIVACY.md. Check changed destinations and factual attribution.
A project link is not evidence that its deployment or benchmark was verified.
No application build is configured for this profile.
